# Security Policy

## Responsible disclosure

If you find a vulnerability in the code or content of this repository, please report it privately:

- Email: work@sayedabdou.com
- Subject: `[ai-red-team-lab] Security Issue`

Please include a description, reproduction steps, and affected files. Do not open a public issue for security findings. I will acknowledge within 72 hours and aim to resolve within 14 days.

## Ethical use

This repository contains adversarial testing knowledge and tooling. It is published for **defensive security research, authorized red teaming, and education**. Using these materials against systems without explicit authorization is illegal and not condoned.

If you use any part of this repository in an engagement, ensure you have:
1. Written authorization / scope from the system owner.
2. A defined rules-of-engagement, including stop conditions.
3. A data-handling plan (findings, evidence, PII redaction).
